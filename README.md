# 🎬 Film Booking System

A Java Swing-based GUI application integrated with MySQL database for managing movies, customers, and bookings.

## 🚀 Features
- Add, Update, Delete Movies
- Manage Customers
- Booking System with Date & Seats
- Automatic Table Refresh
- User-friendly GUI

## 🛠 Technologies Used
- Java (Swing)
- MySQL
- JDBC
